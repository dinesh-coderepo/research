# 📖 Glossary

A quick-reference for the jargon you'll meet in patent + paper land.

| Term | Meaning |
|---|---|
| **Abstract** | 150–250 word summary at the top of a paper or patent. |
| **Anywhere on Earth (AoE)** | Time zone used by conference deadlines. UTC−12. So "Nov 17 AoE" = Nov 18 14:00 IST. |
| **arXiv** | Open pre-print server (arxiv.org). Posting locks priority date but is *public*. |
| **Camera-ready** | Final version of an accepted paper, formatted for proceedings. |
| **CFP** | Call for Papers. |
| **Claim** | The legally-defined scope of a patent. The most important part. |
| **Co-pending** | Two patent applications by the same inventor on related subjects. |
| **CRM claim** | "Computer-readable medium" — software-product-form claim type. |
| **CMT** | Conference Management Toolkit (cmt.research.microsoft.com) — submission portal for many venues. |
| **D&B** | Datasets & Benchmarks (NeurIPS track). |
| **DEEM** | Data Engineering Meets Machine Learning workshop @ SIGMOD. |
| **DOI** | Digital Object Identifier — unique URL for a paper. |
| **Endorsement (arXiv)** | One-time approval needed to post in CS for first-time authors. |
| **Espacenet** | European Patent Office's free patent search. |
| **First-to-File** | The system in most countries (incl. US since 2013): whoever files first wins. |
| **Grace period** | US: 1 year between first public disclosure and patent filing. EU/IN: 0 (absolute novelty). |
| **IDF** | Invention Disclosure Form. Internal first step for patenting. |
| **Independent claim** | A self-contained patent claim. |
| **IP** | Intellectual Property. |
| **MSR** | Microsoft Research — the dedicated research org. |
| **Non-provisional** | A regular full patent application. 20-year term. |
| **Office Action** | A USPTO examiner's written objection during prosecution. |
| **Open Access (OA)** | Free public access to a paper. Microsoft Research has an OA policy. |
| **PCT** | Patent Cooperation Treaty — file once, cover ~150 countries (with later national-phase entries). |
| **PI** | Principal Investigator (academic-style lead). |
| **Prior art** | Anything published before your filing date that's relevant. |
| **Provisional** | A 12-month "placeholder" patent application. Cheap. |
| **Reviewer 2** | The harsh anonymous reviewer of academic legend. |
| **Section 3(k)** | Indian Patents Act — software *per se* not patentable in India. |
| **Shadow execution** | Running the new system in parallel with the old, comparing outputs. |
| **Specification** | The narrative + drawings part of a patent (everything but the claims). |
| **TLDR** | Too Long; Didn't Read. Also a Semantic Scholar feature that auto-summarizes papers. |
| **USPTO** | United States Patent and Trademark Office. |
| **VLDB** | Very Large Data Bases — top data-systems conference. |
| **WikiCFP** | wikicfp.com — community-maintained list of conference deadlines. |

🎯 **Action.** Bookmark this file. Add new terms as you learn them.
