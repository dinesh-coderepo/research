# 🧰 Tools & Resources

A curated toolbox. Most are free; a few have a freemium tier that's plenty for one researcher.

## ✍️ Writing

| Tool | What it's for | Free? |
|---|---|---|
| **Overleaf** | Collaborative LaTeX in the browser. Microsoft SSO works. | ✅ free tier OK; paid for private projects |
| **VSCode + LaTeX Workshop** | Local LaTeX editing (for offline / confidential work) | ✅ free |
| **Typst** | Modern LaTeX alternative — faster compilation | ✅ free |
| **Grammarly / LanguageTool** | Grammar + style — **don't paste confidential text into web tools**; use offline plugin if available | freemium |

## 🔗 References

| Tool | What it's for | Free? |
|---|---|---|
| **Zotero** | Open-source reference manager. Browser extension grabs citations in 1 click. | ✅ free |
| **Mendeley** | Closed-source equivalent (Elsevier) | ✅ free |
| **BibTeX / BibLaTeX** | Citation file format — Zotero exports to it | ✅ free |
| **DBLP** | Authoritative CS bibliography | ✅ free |

## 🧠 Discovery

| Tool | What it's for | Free? |
|---|---|---|
| **Connected Papers** | "Show me papers like this paper" graph view | freemium |
| **Semantic Scholar** | AI-powered citation graph + TLDR summaries | ✅ free |
| **Google Scholar** | Broad search; create alerts on author + topic | ✅ free |
| **arXiv-sanity-lite** | Personalized arXiv feed | ✅ free |
| **Papers with Code** | Models + benchmarks + leaderboards | ✅ free |
| **OpenReview** | NeurIPS / ICLR open reviews — read past papers + reviews | ✅ free |

## 🎓 Learning resources

- **Simon Peyton Jones — How to write a great research paper** (YouTube, ~50 min). Watch this.
- **Larry McEnerney — The Craft of Writing Effectively** (UChicago, YouTube). Watch twice.
- **CMU 15-712 / Berkeley CS294 lecture notes** — distributed systems.
- **The Morning Paper** (blog by Adrian Colyer) — one paper a day.
